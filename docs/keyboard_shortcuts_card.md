## 📁 File Operations

| Shortcut | Action | Notes |
|:---------|:-------|:------|
| `Ctrl+N` | New Project | Create new project |
| `Ctrl+O` | Open Project | Open saved file |
| `Ctrl+S` | Save Project | Save current project |
| `Ctrl+Shift+S` | Save As | Save with options |
| `Ctrl+E` | Export | Export geometry |
